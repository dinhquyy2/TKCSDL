# OISM - Hệ thống quản lý bán hàng và tồn kho đa kênh

## 1. Tổng quan dự án

OISM (Omnichannel Inventory and Sales Management System) là hệ thống quản lý sản phẩm, tồn kho, đơn hàng, bán hàng và các hoạt động nghiệp vụ liên quan trên nhiều kênh bán hàng.

## 2. Phạm vi dự án

Phạm vi hiện tại của dự án tập trung vào:

- Phân tích và thiết kế hệ thống
- Thiết kế cơ sở dữ liệu
- Triển khai cơ sở dữ liệu PostgreSQL
- Kiểm tra tính toàn vẹn và xác thực cơ sở dữ liệu
- Xây dựng tài liệu hệ thống
